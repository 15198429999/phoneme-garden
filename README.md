在线首页主文件从 13,279,834 字节减至约 89 KB。首页角色和背景图片独立加载；按钮不再排在十多兆内嵌素材之后。选择关卡后，只下载该关的战斗素材，前三关无需下载僵王骨骼与贴图。

- 音效单项等待上限20秒；不可用时提示并允许继续练习。
- 题库、出怪节奏、植物攻击、僵王与终结动画未作改动。

## 使用与离线版

在线访问上面的原网址。下载 [offline.html](offline.html) 后可作为完整单文件版保存，所有图片、动画和声音内嵌；它体积较大，不作为默认在线入口。

[source.zip](source.zip) 包含可编辑源文件、素材来源和测试。源码运行 `node server.mjs`；`node build-online.mjs` 生成在线发布目录，`node build-offline.mjs` 生成离线文件。请上传在线目录全部文件，不要再用离线文件覆盖在线首页。

- 简单、困难两种难度，各有四个自由关卡。
- 12个单元音、8个双元音、28个教学辅音和48个混合音标。
- 第四关固定僵王投放带音标的僵尸，玉米炮沿弧线攻击；48题后展示完整击败过程。
- 支持触控、暂停、静音与浏览器支持的全屏。
