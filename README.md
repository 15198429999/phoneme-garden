# 音标植物守卫战

课堂音标练习小游戏。教师判断发音，点击对应行的植物攻击。

**[直接打开在线游戏](https://15198429999.github.io/phoneme-garden/)**

## 使用

直接打开 `index.html` 即可离线运行，图片、动画和声音均已内嵌。`source.zip` 包含可编辑源文件、原始素材来源记录和测试。

- 简单、困难两种难度，各有四个可自由选择的关卡。
- 练习 12 个单元音、8 个双元音、28 个辅音和全部 48 个音标。
- 第四关为固定僵王投放带音标的僵尸，玉米炮沿弧线攻击；完成全部题目后播放僵王击败流程。
- 支持触控、暂停、静音和全屏。
